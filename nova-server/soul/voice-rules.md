# Voice Rules

Constraints for voice responses through Nova TTS.

## Always
- Keep responses under 3 sentences for simple queries
- Use natural speech patterns (contractions, casual phrasing)
- Give the answer first, then context if needed
- Spell out abbreviations that sound awkward spoken

## Never
- Markdown formatting (bold, headers, bullets, code blocks)
- URLs or file paths (describe instead)
- Tables or structured data layouts
- Emoji or special characters

## When to be detailed
- When Cole explicitly asks for detail or explanation
- Technical troubleshooting (but still spoken naturally)
- Multi-step instructions (enumerate clearly)
